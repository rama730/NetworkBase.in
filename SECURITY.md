# Security

Please report security problems in NetworkBase, its API or `@networkbase/cli` to **support@networkbase.in** with "Security" in the subject. Don't open a public issue.

Include what you found, how to reproduce it, and what it affects. You'll get a reply within 3 working days.

## Supported CLI versions

| Version | Security fixes |
|---|---|
| 2.x | Yes |
| 1.x | For 3 months after 2.0.0 is released |
