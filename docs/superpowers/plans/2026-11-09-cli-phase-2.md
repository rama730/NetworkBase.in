# CLI Phase 2 — CLI 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the 5,393-line `bin/nb.mjs` with CLI 2.0: the §17 command language, the folder as working copy with three-way sync that never overwrites, honest output and exit codes, safe sign-in, and the terminal design system — zero runtime dependencies.

**Architecture:** `bin/nb.mjs` only parses, dispatches, prints and exits. Modules under `lib/` return data; printers in `lib/print/` own stdout/stderr. The server API from Phase 1 (`/api/v1/me`, `/files/place`, `/workspaces/:id/manifest`, `/tasks/count`, docs routes) plus the 1.x extension routes for tasks. Tests drive the CLI as a black box against `test/helpers/fake-server.mjs`.

**Tech Stack:** Node ≥ 20, ESM, JSDoc + `tsc --checkJs`, `node:test`.

**Spec:** report §17, §27 (A1), §29 (A3.1 browser row, A3.8, A3.9, A3.11–A3.14, A3.16), §30 (A4), §31 (A5), §32 (A6.2–A6.7), §38 (A12); master plan P2.1–P2.10.

## Global Constraints

- No runtime dependencies; `engines.node >=20`; bins `nb`, `networkbase`.
- stdout = results only; everything else on stderr. `--json` envelope `{ ok, schema, data }` / `{ ok:false, error:{ code, message, hint, details } }`.
- Exit codes: 0 ok · 1 error · 2 usage · 3 not signed in/no access · 4 conflict · 5 blocked · 6 needs input · 7 needs confirmation · 8 offline · 130 cancelled.
- Never overwrite a local file whose hash differs from its base; never send a token to an origin other than the one that issued it.
- Role words reference / draft / final.

## Review Focus

- A file edited locally and remotely → conflict copy, exit 4, nothing lost.
- A cloned folder with a 1.x `.networkbase/config.json` naming another `apiUrl` → ignored with a warning; token stays with its origin.
- Non-interactive `nb push` with no paths → exit 2, nothing uploaded.
- Task text containing escape sequences → printed harmlessly.
- Killed mid-pull → next run finishes or reports; no half-written file.

## Tasks

1. **Core**: `lib/args.mjs` (command table, `util.parseArgs` strict, did-you-mean, help), `lib/print/*` (style, symbols, width, envelope, tables), `lib/errors.mjs` (codes → exit codes), `bin/nb.mjs`. Tests: help/version/unknown flag/exit codes/JSON envelope.
2. **Config and auth**: `lib/config.mjs` (walk-up root, profiles, env precedence, 1.x migration, 0600/0700), `lib/api.mjs` (origin-bound token, retries, timeouts, idempotency keys, offline), `lib/auth/*` (loopback with PKCE + server support, `--with-token`, logout). Tests with the fake server.
3. **Sync engine**: `lib/sync/*` (ignore rules, local scan + hash cache, manifest, three-way plan, pull/push/sync, conflicts + `resolve`, atomic writes, lock, base copies + diff, `.tasks/`, 1.x mirror migration). Tests for every A1.6 row.
4. **Work commands**: tasks, subtasks, comments, docs, workspaces, members, search, open, count.
5. **Watch, doctor, completion, update notice, setup shell, unlink**.
6. **Terminal design** pass (A5) and snapshot tests; budgets enforced.
7. **Package**: `package.json`, README, CHANGELOG, publish workflow (staged), CODEOWNERS/SECURITY.md.

- `nb activity` needs an activity route → added with P5.2's events endpoint.
- MCP server (`nb mcp`) is rewritten in P3.2; the 2.0 release waits for it.
