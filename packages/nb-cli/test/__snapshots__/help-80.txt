NetworkBase CLI

Usage
  nb <command> [flags]

Most used
  init         Link this folder to a workspace
  status       What changed here, the started task, conflicts
  pull         Download changes; never overwrites your edits
  push         Upload changes; same path = new version
  next         What to work on now: overdue, due soon, in progress
  task list    Tasks (default: yours, not done)
  task start   Make it this folder's task and move it to In progress
  task done    Finish a task (sends it for review when required)
  task create  Create a task (yours unless --to says otherwise)
  inbox        Your notifications, as in the app
